# Agent Instructions

Before performing any task in this repository, every agent must read:

1. [STATE.md](STATE.md) for the current project state and coordination notes.
2. [TASKS.md](TASKS.md) for active work, ownership, status, and handoff rules.

Agents must preserve unrelated worktree changes, update the task status when work starts or finishes, and record blockers in `STATE.md`.
